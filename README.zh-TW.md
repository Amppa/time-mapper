# TimeMapper

[English](README.md) | **繁體中文** | [Español](README.es.md)

一個用來比對多個時區時間的 Chrome 擴充功能。點擊世界地圖上的城市，把它們的一天並排在 24 小時時間軸上，快速找出大家都方便的時間。

---

## 安裝

1. 下載或 clone 這個專案。
2. 開啟 Chrome，進入 `chrome://extensions/`。
3. 打開右上角的「**開發人員模式**」。
4. 點擊「**載入未封裝項目**」，選擇這個專案的根目錄。
5. 點擊 Chrome 工具列上的 TimeMapper 圖示。

---

## 使用方式

**選擇城市** — 點擊世界地圖上的任一圖釘，就能把該城市加到時間軸，再點一次即可移除。第一次開啟時會先預設選取東京、紐約、洛杉磯，以及你瀏覽器的本地時間。

**開啟城市清單** — 頂部工具列的 🏙️ 按鈕可以搜尋任何城市、檢視並調整目前的城市清單、修改城市數量上限、載入範例清單，或全部清除。

**看時間軸** — 每一列是一個城市的 24 小時，直向的**現在線**標出此刻。`00` 那一格會同時顯示日期，方便看出城市在哪裡跨日。

**比對特定時刻** — 在時間軸上點一下就會放下一條對齊線（最多 4 條）。拖曳可以移動位置，點 `[x]` 可以移除。每一列都會即時顯示那個時刻在該城市是幾點。

**使用地圖** — 地圖可以顯示目前的夜間範圍、各時區的小時線，並在已選城市的圖釘上方顯示即時時間泡泡。只想要時間軸的話，地圖區塊可以收合。

## 設定

點擊頂部工具列的 ⚙ 按鈕開啟設定頁面：

| 區塊 | 可以做什麼 |
| --- | --- |
| **語言設定** | 在繁體中文、English、Español 之間切換介面語言。 |
| **小地圖設定** | 開關夜間範圍、小時線與城市時間泡泡；微調地圖的經度／緯度偏移、寬度／高度縮放與垂直偏移；一鍵恢復預設。 |
| **時段設定** | 選擇現在線的基準（瀏覽器本地時間，或第一個城市的時間），再設定三個自訂時段的起迄時間與背景／文字顏色。預設為 08–17、18–23、00–07。 |
| **外觀設定** | 自動、深色或淺色主題。自動會跟隨系統設定。 |

你選的城市、時段與地圖校準值都存在瀏覽器的 `localStorage`，下次開啟時會自動還原。

## 地圖上沒有的城市

在城市清單裡搜尋即可。結果來自 [Open-Meteo 地理編碼 API](https://geocoding-api.open-meteo.com/)，所以搜尋需要網路連線。選取後會依該城市自己的座標放到地圖上，並記住供下次使用。

想把城市永久加進內建清單，請編輯 `src/shared/cities.js` 的 `cityCatalog`；經緯度轉換成地圖位置的常數寫在 `src/shared/config.js` 最上方的 `PROJECTION` 區塊。

## 翻譯檢查

`node tools/check-i18n.mjs` 會檢查 `src/shared/i18n.js` 的字典是否仍涵蓋兩個頁面用到的每個字串。新增介面字串、語言或城市之後跑一次。
